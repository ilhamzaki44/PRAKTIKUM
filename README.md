# Portfolio Website

Website portfolio sederhana yang dibuat untuk tugas slicing website (HTML, CSS, JavaScript).

## Fitur
- Responsive di mobile, tablet, dan desktop
- Menu navigasi dengan toggle di tampilan mobile
- Daftar project yang di-render otomatis pakai JavaScript (DOM)
- Form kontak sederhana dengan validasi bawaan browser

## Teknologi
- HTML5
- CSS3 (plain CSS, tanpa framework)
- JavaScript (vanilla)

## Cara Menjalankan
1. Download / clone repo ini
2. Buka file `index.html` di browser

## Struktur File
├── index.html
├── style.css
├── script.js
└── README.md
